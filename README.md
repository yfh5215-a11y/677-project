# 677-project

This repository contains supporting materials for my MA677 final project on Difference-in-Differences and the parallel trends assumption.

Files:
- code/did_simulation.R: R code for simulating DiD data, estimating the DiD model, and generating figures.
- data/simulated_did_data.csv: Simulated 2x2 DiD dataset.
- data/simulated_event_study_data.csv: Simulated event-study dataset.
- figures/did_trends.png: Plot of treated and control group trends.
- figures/event_study.png: Event-study style plot.
- chatgpt_transcript.txt: Transcript or prompts used with AI assistance.
